My Storyقصتي ورحلتي

My journey into the world of technology began in primary school, when I first developed an interest in programming, web development, and cybersecurity. What started as curiosity gradually grew into a passion for understanding how technology works, building digital experiences, and exploring the systems that power our modern world.

I'm Adam Elgeneral, an Ethical Hacker, Web Developer, and Cyber Security enthusiast. I create modern, responsive websites and explore how digital systems can be understood and protected.

My journey extends beyond web development. As an Ethical Hacker I study system vulnerabilities, practice responsible security research, and develop the attacker mindset needed to build stronger defenses.

What I Do

Ethical Hacking: Identifying vulnerabilities, OSINT, web application security, and thinking like an attacker to protect systems.

Web Development: Building modern, responsive websites using HTML, CSS, JavaScript, and React.

Frontend Development: Creating interactive user interfaces with a focus on usability, performance, and visual consistency.

Cybersecurity: Developing knowledge of digital security, system vulnerabilities, and security principles.

Continuous Learning: Exploring new technologies, improving programming skills, and challenging myself through practical projects.

My Philosophy

I believe technology is more than just writing code — it's about solving problems, transforming ideas into reality, and creating experiences that make a difference.

I'm constantly pushing myself to learn, experiment, and improve. Every project is an opportunity to develop my skills, explore new possibilities, and get one step closer to mastering my craft.

I'm not just learning how technology works — I'm learning how to use it to build something meaningful.

ماذا أفعل

الاختراق الأخلاقي: اكتشاف الثغرات، OSINT، أمان تطبيقات الويب، والتفكير كالمهاجم لحماية الأنظمة.

تطوير الواجهات: إنشاء واجهات مستخدم تفاعلية مع التركيز على سهولة الاستخدام والأداء والاتساق البصري.

الأمن السيبراني: تطوير معرفتي بالأمان الرقمي وثغرات الأنظمة ومبادئ الأمان.

التعلم المستمر: استكشاف تقنيات جديدة وتحسين مهاراتي البرمجية وتحدي نفسي من خلال المشاريع العملية.
